# 의료진 사진 폴더

이 폴더에 의료진 사진을 다음 파일명으로 저장하면 자동으로 사이트에 표시됩니다.

| 파일명          | 사용 위치                                       |
| --------------- | ----------------------------------------------- |
| doctor-01.jpg   | 이창돈 진료원장                                 |
| doctor-02.jpg   | (이름 미확인) 진료원장                          |
| doctor-03.jpg   | 김새일 진료원장                                 |
| doctor-04.jpg   | 문은수 이사장 · 대표원장                        |
| doctor-05.jpg   | (이름 미확인) 진료원장                          |
| doctor-06.jpg   | (이름 미확인) 임상교수                          |
| doctor-07.jpg   | (이름 미확인) 임상교수                          |
| doctor-08.jpg   | 박수민 진료원장                                 |
| doctor-09.jpg   | (이름 미확인) 임상교수                          |

## 권장 사양

- 가로:세로 = 1:1 또는 4:5 (정방형 / 약간 세로형)
- 최소 800×800px, 권장 1200×1200px
- 배경 흰색 또는 자연광 인물 사진
- JPG 형식, 200KB ~ 1MB 사이

## 이름 매칭 변경 방법

이름이 맞지 않으면 `functions.php` 의 `moondental_get_team()` 배열에서 해당 항목의
`'name'` 만 바꿔주시면 됩니다. 사진 파일명을 바꾸는 대신 코드 한 줄을 수정하세요.
