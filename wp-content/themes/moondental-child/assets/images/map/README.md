# 지도 사진 폴더

오시는 길 페이지의 지도 카드에 **실제 네이버 지도 스크린샷**을 깔려면
이 폴더에 다음 파일명 중 하나로 저장하세요:

- `naver-map.png` (권장)
- `naver-map.jpg` / `naver-map.jpeg` / `naver-map.webp` 도 가능

권장 사양:
- 가로:세로 = 16:9 (예: 1600×900px)
- 1MB 이내
- 네이버 지도에서 병원 마커가 가운데 오도록 캡쳐

파일이 있으면 카드 배경에 자동으로 깔리고, 클릭 시 네이버 지도가 새 탭으로 열립니다.
파일이 없으면 CSS 그라데이션 + 가짜 도로 패턴 카드로 fallback.
